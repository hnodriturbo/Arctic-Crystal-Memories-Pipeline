## Key Takeaways from This Exchange

- Cockpit3D's output format requirement: **3D or 2D point cloud with texture** — not just geometry
- Their pipeline: Upload flat image → AI 3D modeling → Cockpit3D Scene file → edit → export point cloud (DXF for Green Beam, GLB/STL for UV)
- They are **laser agnostic** — support non-Cockpit3D lasers
- **Drop Ship Print Service** available for pre-made landmark crystals (Toronto or potentially China)
- **Free trial** available at cockpit3d.com — includes conversion credits
- JetMini pricing at: https://3dcrystal.com/jetmini
- Larger production models: Drone, Rocket (multi-mode)
- Light bases and accessories available through their portal — good bundling opportunity
