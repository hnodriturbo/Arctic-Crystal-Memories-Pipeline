# requirements-gpu.txt — documentation guard for CUDA workstations
#
# The complete supported stack, including CPU Torch, GFPGAN and Real-ESRGAN,
# now lives in requirements.txt. The Ubuntu production VPS uses that CPU stack.
#
# A CUDA workstation may replace the two +cpu wheels with the paired CUDA 12.1
# builds after installing requirements.txt:
#
#   pip install --force-reinstall \
#     torch==2.1.2+cu121 torchvision==0.16.2+cu121 \
#     --index-url https://download.pytorch.org/whl/cu121
#
# Keep these versions paired: basicsr 1.4.2 imports torchvision's pre-0.17
# functional_tensor module. This file intentionally has no installable entries,
# preventing an accidental CUDA installation on the CPU-only VPS.
