# ACM Learning

Þessi mappa geymir verklegt námsefni sem styður local-first vinnslu Arctic Crystal Memories. Námskeiðin eiga að gera handvirka vinnu endurtekjanlega, mælanlega og örugga svo sama verklag virki á mörgum myndum.

## Námskeið

- [Lagfæring og hreinsun 3D/2.5D módela í Blender](3D-Model-Repair-Course/README.md)

## Aðskilnaður náms og framleiðslu

- Æfingar nota afrit af geometry, aldrei eina eintakið af baseline.
- Stór `.blend`, `.obj` og `.glb` æfinga-output fer í ignored `converter/2.5D-pipeline/output/learning/`.
- Rannsóknarlíkön eru prófuð samkvæmt núverandi leyfum. Commercial dreifing eða þjónusta fær sérstaka leyfisúttekt áður en hún hefst.
- Engu er ýtt á GitHub sjálfkrafa; local skrár eru source of truth.
