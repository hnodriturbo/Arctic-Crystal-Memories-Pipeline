## pipeline-01 — General Depth Anything V2 Pipeline

`pipeline-01` is the main general-purpose portrait pipeline and the current
baseline for K9 crystal image-to-mesh work.

Its default direction is:

1. Real-ESRGAN upscaling
2. REMBG background removal
3. Depth Anything V2 depth estimation
4. Open3D point cloud and mesh generation
5. Full-size export preparation
6. Crystal-size scaling

The pipeline is intended to stay as modern and clean as practical. It should not
be forced to downgrade dependencies just to support one older model. When a model
needs unusual pins, create or use a separate pipeline instead.

Important notes:

- Default depth model: Depth Anything V2
- Useful fallback: MiDaS
- Current depth profile work: `standard`, `soft_edges_v1`, and `soft_edges_feathered`
- Stage 04 mesh generation exists and uses Open3D
- Stage 05 exports validated full-size OBJ/STL/PLY files
- Stage 06 crystal scaling converts full-size exports to physical crystal dimensions

This pipeline is the preferred starting point for general portrait workflow
experiments.

## pipeline-02-zoedepth — Isolated ZoeDepth Pipeline

`pipeline-02-zoedepth` is an isolated test environment for ZoeDepth.

Important notes:

- Required compatibility pin: `timm==0.9.16`
- Purpose: compare metric ZoeDepth maps against the main Depth Anything V2 workflow
- Stage 04 mesh generation is copied from the main pipeline and should be tested against ZoeDepth outputs
- Stage 05 is still a stub
- Stage 06 is not currently included

This pipeline should stay focused on ZoeDepth until that model has been fully
tested and compared against the baseline.

# 21. SSLE Machine Technology — How It Actually Works

## The Laser Type

Subsurface laser engraving uses one of two laser types:

- **Green beam (532nm)** — Traditional. Faster, cheaper machines, most common. Most Chinese manufacturers use this. Recommended for starting a business.
- **UV (355nm)** — Newer, higher resolution, finer detail, better for small intricate engravings. More expensive machines.

Both lasers share the same principle: the beam passes harmlessly through the surface of the crystal and only reacts at the precise point where it is focused inside the crystal.

## How the Laser Creates a Dot

Each laser pulse fires at a precise XYZ coordinate inside the crystal. At that point the energy concentration is high enough to create a microscopic fracture — a tiny void shaped like a bubble. This is called a "bubble" or "micro-fracture."

The bubble is hollow inside and reflects light, making it appear as a white dot when viewed in normal light.

## How Shading and Grayscale Work

There is no actual color in SSLE engraving. All shading is an optical illusion created two ways:

**Method 1: Laser power per pulse**
- Higher power → larger, brighter bubble → appears whiter/more opaque
- Lower power → smaller, dimmer bubble → appears lighter/less visible
- The software assigns a power value to each point based on the depth and intensity data

**Method 2: Dot density**
- Dense cluster of dots → region appears darker/more opaque
- Sparse dots → region appears lighter/semi-transparent

Both methods are used together. The software calculates power values and density per region from the point cloud data. The machine does NOT need the original photo separately at print time — all information (position + power level) is encoded in the point cloud file.

## What the Machine Actually Receives

The machine receives a point cloud file — a list of XYZ coordinates, each with an associated laser power value. Nothing else. The point cloud is generated from your processed mesh/depth map by the SSLE software (like Cockpit3D). After that, the machine just executes the list.

The original photo is NOT sent to the machine. Its data (shading, texture) was used during point cloud generation to assign power values.

## Critical Machine Parameters

- Focal point accuracy: < 100 micrometers
- Average bubble size: tenths of a millimeter
- Typical point count for a portrait: 500,000 – 2,000,000+ points
- Engraving speed: up to 220,000 bubbles per minute (professional machines)
- A standard portrait cube engraves in 3–10 minutes depending on machine and point count

# 22. SSLE Machine Types — Green Beam vs UV

## Green Beam Machines (Recommended Starting Point)

- Wavelength: 532nm
- Crystal requirement: High optical-grade K9 crystal
- Common use: Portraits, logos, gifts, awards
- Point size: ~0.1–0.3mm
- Engraving speed: Fast (100,000–220,000 points/min)
- Machine price range: $3,000–$30,000 (Chinese brands)
- Best for: High-volume commercial work, starting businesses

## UV Laser Machines

- Wavelength: 355nm
- Crystal requirement: Same K9, but results are finer
- Point size: Smaller than green beam — finer detail
- Speed: Slower than green beam
- Price range: $15,000–$65,000+
- Best for: High-detail fine art engravings, premium tier products

## Machine Size Categories

**Table-top / Compact**
- Working area: up to ~200mm x 200mm x 150mm
- Weight: 50–150kg
- Use: Small shop, low to medium volume
- Price: $3,000–$12,000

**Mid-size Production**
- Working area: up to ~300mm x 300mm x 200mm
- Weight: 150–300kg
- Use: Commercial production, medium-high volume
- Price: $12,000–$30,000

**Large Format / Industrial**
- Working area: 400mm+ in any axis
- Weight: 300kg+
- Use: Large trophies, awards, architectural pieces
- Price: $30,000–$65,000+

**Note on shipping to Iceland:** Large machines ship on euro pallets via sea freight. Expect 4–8 weeks from China. The Iceland-China FTA significantly reduces import costs. Budget for: machine price + ~$500–$1,500 freight + local customs fees + installation.

# 25. File Formats — Where Each Belongs in the Pipeline

## OBJ (.obj)

- Stores: Geometry (triangles) + UV texture coordinates + normals + vertex colors + material references (.mtl file)
- Size: Large (contains much more information than STL)
- Editable in: Blender, Meshmixer, ZBrush, Fusion 360, MeshLab, almost everything
- Use in pipeline: Best format for editing and refinement stages. Preserves smooth curved surfaces better than STL.
- For SSLE: Most machine software does NOT accept OBJ directly — you will convert to point cloud in Cockpit3D or similar

**Why OBJ is large:** It stores not just triangles but UV map coordinates for every vertex, allowing textures to be applied correctly. This is also why it is the right format for portrait work — the UV map keeps texture information linked to geometry.

**Why you couldn't open/edit OBJ files before:** You need a 3D editor like Blender or Meshmixer. OBJ files do not open in image viewers or standard file explorers. Blender: File > Import > Wavefront (.obj).

## STL (.stl)

- Stores: Geometry only (triangles). No texture, no UV, no color.
- Size: Smaller than OBJ
- Editable in: Meshmixer, Blender, MeshLab, Fusion 360
- Use in pipeline: Good for purely geometric work (logos, objects, simple shapes). Poor for portrait work (loses all texture information).
- For SSLE: Most machine software also does NOT accept STL directly

## GLB / GLTF (.glb / .gltf)

- Stores: Geometry + textures + animations in a single binary file
- Notes: Some newer SSLE machine software accepts GLB. Cockpit3D mentions GLB support.
- Growing in relevance as machine software modernizes

## BMP / PNG / JPG (2D images)

- What most SSLE software actually accepts for simpler engravings
- Depth bitmaps (grayscale depth maps) exported as BMP are a common input format
- A grayscale BMP where white = closest and black = furthest is a standard depth map input

## Proprietary Point Cloud Formats

- Most SSLE machines use their own .lsf, .pt3, .3dp, or similar proprietary format
- Cockpit3D generates its own optimized point cloud format
- You never create these manually — the SSLE software generates them from your inputs

## Summary: Format per Pipeline Stage

| Stage | Best Format |
|---|---|
| Source photo | JPEG/PNG (highest resolution available) |
| After upscaling | PNG (lossless) |
| After background removal | PNG with alpha channel |
| Depth map | 16-bit PNG or EXR (preserves precision) |
| Point cloud (intermediate) | PLY or XYZ (open format, editable in MeshLab) |
| Mesh (editing) | OBJ (preserves texture + geometry) |
| Mesh (geometry only) | STL (simpler, smaller) |
| Final to SSLE software | Cockpit3D point cloud / BMP depth map / GLB |

# 26. Full Pipeline — Expanded (All Steps)

The workflows in Section 5 are high-level. This is the detailed version for portrait photos:

## Pre-Processing (Before Depth Estimation)

1. **Receive source image** — highest resolution available. Minimum 2MP. Ideal 10MP+.
2. **Evaluate source quality** — check lighting, blur, shadows on face, resolution
3. **Upscale with Real-ESRGAN** — 4x upscale before any other processing. More pixels = better depth map.
4. **Manual image correction** — Photoshop/GIMP: correct lighting balance, increase micro-contrast on face, clean background hints before removal
5. **Background removal** — SAM2 (best precision) or RemBG (fast). Export as PNG with alpha.
6. **Subject isolation check** — Review edges. Manual cleanup in Photoshop if hair, clothing edges are poor.
7. **Optional: Face alignment** — MediaPipe landmarks to align face to standard orientation. Improves depth model results.

## Depth Estimation

8. **Choose depth model** — MiDaS or Depth Anything V2 for portraits. ZoeDepth if metric scale matters.
9. **Run depth estimation** — output is a grayscale depth map (16-bit PNG recommended)
10. **Review depth map** — check: is the nose the closest point? Are eye sockets correct depth? Is the forehead domed properly?
11. **Manual depth correction** — Paint depth corrections in Photoshop using grayscale brush on the depth map. This is expected and normal.
12. **Optional: Face-specific depth override** — Run 3DDFA_V2 or DECA on the face region separately. Blend face-specific depth into the general depth map.

## Point Cloud Generation

13. **Convert depth map to point cloud** — Python script or tool like MeshLab / CloudCompare
14. **Set Z-scale** — control how "deep" the engraving goes. Too much = crashes inside crystal. Too little = flat appearance.
15. **Review point cloud** — check in MeshLab or CloudCompare for artifacts, holes, noise
16. **Point cloud cleanup** — remove noise, fill holes, reduce outlier points

## Mesh Generation (Optional but recommended for portrait editing)

17. **Generate mesh from point cloud** — Poisson Reconstruction in MeshLab or Open3D
18. **Export as OBJ** — for manual editing
19. **Open in Blender or Meshmixer** — review the face
20. **Manual sculpting/correction** — fix nose shape, smooth forehead, correct chin, fix eye sockets if needed. This is the craft stage.
21. **Re-export as OBJ** — save edited mesh

## SSLE Production Preparation

22. **Import into Cockpit3D** — or machine's SSLE software
23. **Set crystal dimensions** — match actual crystal blank being used
24. **Adjust depth scale** — how deep the image sits in the crystal
25. **Adjust point density** — balance quality vs. engraving time
26. **Preview point cloud** — review how it will look before committing
27. **Generate production file** — Cockpit3D exports optimized point cloud for the laser
28. **Send to laser machine**

## Post-Engraving

29. **Quality check crystal** — look for crashes, missing areas, depth issues
30. **Document result** — photo of finished crystal, note settings used, log in project records
